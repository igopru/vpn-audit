# 🚫 Ограничения системы VPN Audit

> **Кратко:** Логи VPN не подходят для учёта рабочего времени и расчёта заработной платы.

---

## 📋 Назначение системы

VPN Audit System создана для **аудита информационной безопасности** и **автоматического управления доступом** к корпоративной VPN-инфраструктуре.

### ✅ Корректные сценарии использования

| Задача | Как система помогает |
|--------|----------------------|
| **Защита периметра** | Автоматическое отключение неактивных пользователей из AD-группы доступа |
| **Экономия лицензий** | Выявление "спящих" учётных записей, не использующих VPN месяцами |
| **Соответствие политикам** | Принудительное применение правила "не подключался 30 дней = отключён" |
| **Выявление аномалий** | Подозрительные подключения в нерабочее время, множественные IP |
| **Аудит уволенных** | Находит учётки в AD-группе, которых уже нет в системе |
| **Управление исключениями** | Гибкие правила для аудиторов, VIP, сотрудников в отпуске |

### ❌ Некорректные сценарии использования

| Задача | Почему не подходит | Риск |
|--------|-------------------|------|
| **Расчёт зарплаты** | Логи не отражают фактическое рабочее время | Недоплата/переплата сотрудникам, трудовые споры |
| **Контроль эффективности** | VPN-подключение ≠ продуктивная работа | Демотивация коллектива |
| **Фиксация прогулов** | Отсутствие сессии ≠ отсутствие работы | Юридические претензии |
| **Налоговый/кадровый учёт** | Данные не соответствуют требованиям ТК РФ | Нарушения при проверках |

## 🔬 Технический анализ ограничений

### Что фиксирует Cisco ASA
```bash
722051: User <ivanov> IP <1.2.3.4> IPv4 Address <10.100.1.50> assigned to session
722037: User <ivanov> IP <1.2.3.4> SVC closing connection: Transport closing
```

**Эти логи говорят только:**
- ✅ Туннель установлен в момент T1
- ✅ Туннель разорван в момент T2
- ❌ **НЕ** говорят, работал ли пользователь в этот промежуток

### Сценарии, искажающие данные

#### 1. Перезагрузка оборудования
При перезагрузке ASA все активные сессии теряются. Логи `722037` **не генерируются**.
- **Результат:** сессии без `end_time`, либо с огромной длительностью после восстановления
- **Пример:** сессия 45 часов в реальной эксплуатации (обнаружено в сентябре 2026)

#### 2. Сетевой сбой на стороне клиента
Клиент отваливается без штатного отключения.
- **Результат:** сессия "висит" в ASA до срабатывания DPD-таймаута (может быть часы)
- **Время работы:** неизвестно (от 0 до полного таймаута)

#### 3. Засыпание ноутбука / закрытие крышки
Клиентское ПО не отправляет лог разрыва.
- **Результат:** сессия активна, пока пользователь не проснётся и не отключится вручную
- **Время работы:** момент засыпания ≠ момент записи лога

#### 4. Смена сети (Wi-Fi → 4G → офис)
Старая сессия не закрывается, новая стартует с новым IP.
- **Результат:** две независимые сессии, промежуток между ними не зафиксирован
- **Время работы:** неизвестно, был ли разрыв в работе

#### 5. Нештатное завершение клиента
Пользователь "убил" процесс AnyConnect, выключил питание.
- **Результат:** лог `722037` не генерируется вообще
- **Время работы:** известно только начало

### Реальная статистика (производственная эксплуатация, сентябрь 2026)

| Метрика | Значение | Комментарий |
|---------|----------|-------------|
| Сессий без `end_time` старше 1 дня | **58** | ASA не прислала лог разрыва |
| Сессий длительностью > 8 часов | **20** | Физически невозможно при таймауте 8ч |
| Максимальная аномальная длительность | **45 часов** | Сессия "висела" 2 суток без логов |

**Эти аномалии — не ошибка парсера, а свойство источника данных.**

## ⚖️ Юридические аспекты

### Трудовой кодекс РФ
- **Ст. 91:** Рабочее время — время, в течение которого работник должен исполнять трудовые обязанности
- **Ст. 189:** Правила внутреннего трудового распорядка
- **Ст. 21:** Работник имеет право на своевременную и в полном объёме выплату заработной платы

### Риски использования VPN-логов для зарплаты

1. **Недоплата:** неучтённые сессии (потерянные логи)
2. **Переплата:** учёт времени простоя как рабочего (висящие сессии)
3. **Трудовые споры:** сотрудник оспорит расчёт в суде, суд запросит доказательства точности
4. **Проверки ГИТ:** инспекция может признать систему учёта ненадлежащей
5. **Репутационный ущерб:** демотивация коллектива

### Что можно использовать в суде
- ✅ Табели учёта рабочего времени (унифицированные формы Т-12, Т-13)
- ✅ Логи входа/выхода в домен (при наличии политик)
- ✅ Системы тайм-трекинга с подтверждением сотрудника
- ❌ **Логи VPN — не подходят**, так как не отражают факт работы

## 💡 Рекомендуемые альтернативы

| Задача | Решение | Точность |
|--------|---------|----------|
| **Учёт рабочего времени** | Специализированные системы (Hubstaff, Toggl, TimeCamp) | Высокая |
| **Табельный учёт** | 1С:ЗУП, Контур.Персонал, SAP HCM | Юридически значимая |
| **Контроль активности** | Логи домена + подтверждение руководителя | Средняя-высокая |
| **Аудит безопасности** | **VPN Audit System** (этот проект) | Высокая для своей задачи |

### Оптимальная комбинация
1. **Безопасность:** VPN Audit System (этот проект)
2. **Учёт времени:** тайм-трекер или доменные логи
3. **Зарплата:** кадровая система с ручным подтверждением

## 🤝 Ответственность

Разработчики VPN Audit System:
- ✅ Гарантируют корректную работу для заявленных задач (аудит безопасности)
- ❌ **Не несут ответственности** за использование системы для расчёта заработной платы или кадровых решений
- ❌ **Не предоставляют** гарантий точности данных для целей, выходящих за рамки аудита безопасности

Любое использование системы для расчёта рабочего времени — **на собственный риск эксплуатирующей организации**.
